# Tour Package Automation

Automated content creation for WordPress & WooCommerce using AI (Gemini) and Excel.

## Quick Start

```bash
# Backend
cd backend
npm install
cp .env.example .env   # Edit with MONGODB_URI, GEMINI_API_KEY
npm run dev

# Frontend (new terminal)
cd frontend
npm install
npm run dev
```

Open http://localhost:3000
